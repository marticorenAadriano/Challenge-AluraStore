Descripción del proyecto

Este proyecto analiza el desempeño de cuatro tiendas utilizando datos de ventas, costos de envío, calificaciones de clientes y productos vendidos. El objetivo principal es identificar cuál de las tiendas es menos eficiente para recomendar su venta, basándose en métricas objetivas obtenidas de los archivos CSV suministrados por Alura.

Estructura del análisis

El proyecto incluye:

-Carga y unión de los datos de ventas, tiendas, productos y envíos.
-Creación de nuevas columnas calculadas (como ingreso y coste de envío promedio).
-Análisis exploratorio para obtener:

  -Ingreso total por tienda.
  -Categorías de productos más y menos vendidas.
  -Calificación promedio por tienda.
  -Productos con mayor y menor número de transacciones.
  -Costo de envío promedio por tienda.
  -Visualizaciones para apoyar las conclusiones.

Tecnologías utilizadas
-Python
-Google Colab
-Pandas
-Matplotlib / Seaborn

Conclusión del análisis

Tras evaluar todos los indicadores, se determinó que la Tienda 4 es la menos eficiente, ya que presenta:

1) El ingreso total más bajo
2) Una de las calificaciones más bajas
3) Menor rendimiento general en relación con las demás tiendas

Por lo tanto, se recomienda que el Sr. Juan venda la Tienda 4.
